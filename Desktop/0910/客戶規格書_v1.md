# VELTRA CYCLES — Frame Supply Specification

**Document No.** VC-SPEC-EF22　　**Revision** 1.0　　**Issue Date** 2026-01-15
**Product** E-Bike Aluminium Frame, Model EF-22 (City / Trekking)
**Supplier** 捷輪工業 / Jielun Industrial Co., Ltd.

---

## 1. Scope

This specification defines the material, dimensional, surface and documentation
requirements for the EF-22 aluminium e-bike frame supplied to VELTRA CYCLES for
the European market.

## 2. Material

| Item | Requirement |
|---|---|
| Main tubes | Aluminium alloy 6061-T6 |
| Rear triangle | Aluminium alloy 6061-T6 |
| Battery mount bracket | Aluminium alloy 7005-T6 |
| Material certificate | Mill certificate required for every lot |

Substitute materials of equivalent or superior grade may be used with prior
written approval from VELTRA engineering. Approval requests must be submitted
at least 20 working days before production.

## 3. Dimensional Requirements

| Item | Nominal | Tolerance |
|---|---|---|
| Head tube angle | 68.5° | ±0.3° |
| Seat tube angle | 73.0° | ±0.3° |
| Bottom bracket width | 68 mm | ±0.2 mm |
| Rear dropout spacing | 148 mm | ±0.5 mm |
| Frame weight (size M, bare) | — | max. 1,850 g |

## 4. Welding

| Item | Requirement |
|---|---|
| Process | TIG |
| Weld bead width | 3.5 mm ±0.5 mm |
| Undercut | max. 0.3 mm depth |
| Porosity | no pore > 0.8 mm diameter |
| Visual inspection | sampling, 10% of each lot |

Rework is permitted once per location. Frames requiring a second rework at the
same location shall be scrapped.

## 5. Surface Treatment

| Item | Requirement |
|---|---|
| Process | Powder coating |
| Coating thickness | 60–90 µm |
| Salt spray test (ISO 9227) | **480 h**, no blistering or red rust |
| Adhesion (ISO 2409) | Class 1 or better |
| Colour deviation | ΔE ≤ 1.5 against approved master panel |

## 6. Marking and Traceability

Each frame shall carry a laser-etched serial number on the bottom bracket shell.
The serial shall encode: supplier code, production year, week, and sequence.
Traceability records shall be retained for 5 years.

## 7. Packaging

Individual carton with EPE foam protection at head tube, bottom bracket and
dropouts. Maximum 4 frames per master carton.

## 8. Delivery

| Item | Requirement |
|---|---|
| Lead time from PO confirmation | 45 calendar days |
| Delivery tolerance | −0 / +3 days |
| Incoterms | FOB Taichung |

## 9. Documentation to accompany each shipment

1. Packing list
2. Mill certificates
3. Inspection report (dimensional + visual)
4. Salt spray test report (per production batch)
